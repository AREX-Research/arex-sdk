# Security policy

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/AREX-Research/arex-sdk/security/advisories/new) to open a private security advisory for this repository. Do not disclose vulnerabilities in public issues or pull requests.

Include the affected SDK and version, a minimal reproduction, the potential impact, and any relevant environment details. Remove API keys, authorization headers, and other secrets from reports and attachments. If a key may have been exposed, revoke it and create a replacement.

Maintainers will coordinate investigation, remediation, and disclosure through the private advisory. Use the latest published SDK release when evaluating whether an issue still applies.

For non-security bugs or general questions, use the repository's public issues instead.
